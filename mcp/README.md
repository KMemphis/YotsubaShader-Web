# yotsubashader-mcp

MCP server for AI assistants: the `reference/` pages of learn.yotsubashader.com (English and Spanish), the analyzer diagnostics and **100 example shaders, 20 for each syntax** (hlsl, glsl, msl, vulkan, wgsl).

```json
{ "mcpServers": { "yotsubashader": { "command": "yotsuba", "args": ["mcp"] } } }
```

The recommended server is the one built into the .NET tool (`dotnet tool install -g YotsubaShader.Compiler.CLI`; code in `Core/YotsubaShader.Mcp` of the compiler repo). This folder is the Node build of the same server, kept for the hosted Worker; its config is

```json
{ "mcpServers": { "yotsubashader": { "command": "node", "args": ["src/stdio.mjs"] } } }
```

Tools: `search_docs`, `list_docs`, `get_doc`, `list_diagnostics`, `get_diagnostic`, `list_examples`, `get_example`, `search_examples`. Resources: `yotsuba://docs/{lang}/{slug}`, `yotsuba://examples/{id}`. Prompt: `write_shader`.

## Layout

| Path | What |
| --- | --- |
| `src/api.mjs` | The queries (pure functions, tested). |
| `src/core.mjs` | Builds the `McpServer` with the tools, resources and the prompt. |
| `src/stdio.mjs` | The `npx` entry point (stdio). |
| `src/worker.mjs`, `wrangler.toml` | The same server over Streamable HTTP for Cloudflare Workers (`/mcp`). |
| `data/docs-{en,es}.json` | Generated by `../learn/tools/gen-mcp-data.mjs` from `learn/content/*/reference`. |
| `data/examples.json`, `examples/<style>/*.cs` | Generated by `tools/build-examples.mjs`. |
| `tools/recipes.mjs`, `tools/styles.mjs` | The 20 shared effects, written once in the GLSL dialect, and the table that rewrites them into each syntax. |
| `examples-check/` | Compiles every example with the IDE analyzer. |

## Regenerate

```bash
npm run data          # docs + examples
npm test              # API and protocol tests
```

The 7 GLSL examples and the HLSL ocean of the playground (`../src/playground-examples`) are copied as they are; the recipes fill every syntax up to 20.

## Check the examples

Two checks, both against the compiler repository (it must be at `../../`):

```bash
dotnet build examples-check/Check.csproj      # C# + analyzer, all 100 examples
dotnet run --project ../../Core/YotsubaShader.Compiler.CLI -- compile examples-check/Check.csproj \
  --target spirv --target glsl --target gles --target wgsl --target msl --target hlsl --output /tmp/out
```

All 100 compile for every target; only `glsl-bricks` and `glsl-pool` (they use `sampler2D`) are rejected by WGSL.

## Publish

`npm publish` for the package; `npx wrangler deploy` for the Worker (set the route once the domain is confirmed).
