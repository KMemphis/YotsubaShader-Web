# Reference PDFs

Two documents, each in English and Spanish, published in `src/static/downloads/`:

| File | Content | Data |
|---|---|---|
| `yotsuba-shader-syntax-reference-{en,es}.pdf` | Every concept in the HLSL, GLSL, MSL, SPIR-V and WGSL syntaxes | `src/reference.mjs` and the sources of the `YotsubaShader.<X>Syntax` projects |
| `yotsuba-shader-backend-compatibility-{en,es}.pdf` | Which backends support each concept | `tools/compat/compat.json` |

Build: `./build.sh` (needs Typst and Node). The tables are generated by `tools/gen-data.mjs` into `generated/`; the prose is in the four `.typ` files. The look comes from `../guide/template.typ`.

To refresh the compatibility data, run `node tools/compat/run.mjs` from `Web/` first (see `tools/compat/README.md`).
